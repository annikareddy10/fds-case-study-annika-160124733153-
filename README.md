Project Overview

This repository contains the Jupyter Notebook for the Fundamentals of Data Science case study assignment. It covers two case studies involving data analysis, visualisation, clustering, and classification.

Case Studies

Case Study 1: Online Retail

* Exploratory data analysis of retail transactions.
* Market basket analysis and association rules.
* Principal Component Analysis (PCA).
* Clustering and comparison of clustering methods.
* Visualisation and interpretation of results.

Case Study 4: Student Data and Performance

* Exploratory analysis of student data.
* Analysis of student outcomes.
* Statistical testing using the Kruskal–Wallis test.
* Classification using logistic regression.
* Model evaluation using classification metrics and a confusion matrix.

Technologies Used

* Python
* Jupyter Notebook / Google Colab
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* SciPy

How to Run

1. Open jupyter_annika.ipynb in Google Colab or Jupyter Notebook.
2. Connect to a runtime if using Google Colab.
3. Run all cells from top to bottom.
4. Review the generated outputs, visualisations, and evaluation metrics.

The notebook downloads the required datasets when executed, so an internet connection is needed.

Repository Contents

Conclusion

The project applies data science techniques to retail transaction analysis and student performance data, using exploratory analysis, statistical methods, clustering, and classification.
